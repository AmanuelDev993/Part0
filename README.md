# Full Stack Open – Part 0

This repository contains my solutions for **Part 0: Fundamentals of Web Apps** of the Full Stack Open course.

The exercises focus on understanding how web applications work, including:

* HTTP requests and responses
* Browser and server communication
* Traditional web applications
* Single-page applications (SPA)
* Creating and sending data with HTTP POST requests
* Sequence diagrams using Mermaid

The diagrams in this repository visualize the communication between the browser and server when loading the notes application and creating new notes.
